# Machine Learning Module & Model Artifacts

This directory contains ML models, training scripts, evaluation benchmarks, and Jupyter notebooks.

## Subdirectories:
- `datasets/`: Pre-loaded and synthetic evaluation datasets.
- `notebooks/`: Exploratory Jupyter notebooks for ML/DL models.
- `training/`: Training and validation scripts.
- `models/`: Saved model artifacts (`.pkl`, `.pt`).
- `evaluation/`: Model performance metrics, confusion matrices, and ROC curves.
